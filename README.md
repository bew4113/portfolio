## 🚀 Key Projects

### TENCYBER Platform
**Unified Cybersecurity Platform & SIEM**

ระบบ Centralized Log Management และ SIEM ประสิทธิภาพสูง ออกแบบตามหลักการ Single Pane of Glass รองรับ Log มหาศาลด้วย ClickHouse (Hot Tier) และ MinIO (Cold Tier) พร้อมหน้า Dashboard 3D Visualization

**Stack:** Next.js 14, ClickHouse, Vector, MinIO, Three.js, Zod

### Smart Log Pipeline
**High-Throughput Ingestion Architecture**

ออกแบบ Pipeline การไหลของข้อมูลด้วย Vector.dev เพื่อทำ ETL (Extract, Transform, Load) ข้อมูล Log จาก EDR/Firewall ก่อนบันทึกลง Database ช่วยลดภาระ Server และประหยัดพื้นที่จัดเก็บด้วย LZ4 Compression

**Stack:** Vector, Lua Script, Docker, Linux Optimization

### Secure Gateway & Auth
**5-Layer Security Architecture**

วางระบบความปลอดภัย 5 ชั้น (Network, App, Auth, System, Data) ตั้งแต่ Cloudflare WAF, Nginx Rate Limiting ไปจนถึง 2FA/TOTP และ RBAC เพื่อป้องกันการโจมตีทางไซเบอร์ครบวงจร

**Stack:** Nginx, Cloudflare, JWT, Redis, Helmet.js
